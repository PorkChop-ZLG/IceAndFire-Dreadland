# Ice And Fire: Dread Land（冰火传说：悚域）

欢迎来到 **冰火传说：悚域**——一个为 **Ice And Fire: Community Edition** 打造的附属模组。这里的悚域不是只有冰天雪地，而是由冰、火、雷、悚四个世界组成的全新冒险维度。

> ⚠️ **开发状态：早期 Alpha**
>
> 当前版本大量内容尚未完工，**悚怖女皇 BOSS 战、其他 BOSS 和生物均未完成**。现在可完整体验的主线到“悚域”为止，后续内容仍在开发中。

---

## ✨ 模组特色

- **全新悚域维度**：包含冰域、火域、雷域、悚域四大区域，各自拥有独立地貌、结构与生物。
- **三座教堂与地牢**：寻找寒冰、烈火、雷电教堂，抵御悚怖生物，深入教堂地牢挑战巨龙。
- **四把钥匙**：冰域之钥、火域之钥、雷域之钥、悚域之钥，集齐后合成悚域之钥。
- **悚域传送门**：用悚砖搭建 5×7 框架，用悚域之钥右键框架以激活悚域传送门。
- **雷域特色机制**：会自然生成大量雷电，极具视觉震撼。

---

## 🎮 玩法流程

1. 找到 **寒冰教堂 / 烈火教堂 / 雷电教堂**。
2. 帮助教堂击退来袭的 **悚怖生物**，收集 **悚怖碎片**。
3. 用悚怖碎片向教堂牧师兑换 **陵主之钥**。
4. 挖开教堂地板 **十字架中央的方块**，进入地牢。
5. 用陵主之钥打开地牢大门，挑战镇守钥匙的 **冰龙 / 火龙 / 电龙**，分别获得 **冰域之钥 / 火域之钥 / 雷域之钥**。
6. 集齐三把钥匙，合成 **悚域之钥**。
7. 前往冰火传说（Ice And Fire）原版结构中的 **悚陵**，用陵主之钥打开大门，深入悚陵，找到最深处 **悚域传送门框架**。
8. 手持悚域之钥右键框架，激活传送门，进入 **悚域**。

> 当前版本主线到此完结，后续内容正在开发中。

## 🌍 悚域维度

这是一个不同于 Ice And Fire 原版设定的悚域：

- **冰域**：冰霜覆盖的平原与森林，寒冷寂静。
- **火域**：焦黑龟裂的灼热大地，遍布熔岩与火焰。
- **雷域**：雷暴频发，苦力怕会被闪电转化。
- **悚域**：阴森诡谲的核心地带，生长悚木，也是冒险的终点。

每个域都有自己的地貌、结构和生物，并且都有一个 BOSS 等待挑战（BOSS 暂未完成）。最终 BOSS **悚怖女皇** 与她的坐骑 **黑霜** 已确定会完成，其余三个 BOSS 尚未开始设计。

## 📦 安装

1. 安装 Minecraft 1.21.1 与 NeoForge。
2. 下载并放入 **Ice And Fire: Community Edition**、**Jupiter** 和本模组到 `mods` 文件夹。
3. 启动游戏即可。
